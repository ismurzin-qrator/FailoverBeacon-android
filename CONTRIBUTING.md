# Contributing

Follow the existing conventions and style of the code.

Run `./gradlew check` before opening a pull request. It must pass.

Fork the repository and open a pull request. Pull requests are squashed on merge. The pull request
title follows [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).

Sign off every commit under the [Developer Certificate of Origin](https://developercertificate.org/)
with `git commit -s`.
